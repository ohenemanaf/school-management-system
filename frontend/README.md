# Frontend

React + Vite application for the School Management System. See the [project setup instructions](../README.md) for the backend, database and local development workflow.

- `npm ci`: install locked dependencies
- `npm run dev`: start the development server
- `npm run lint`: check source quality
- `npm run build`: build the production bundle
- `npm run preview`: preview the production bundle locally

Copy `.env.example` to `.env` to configure `VITE_API_URL` when using a different backend address.
